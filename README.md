# CDPO Quiz Platform

A study and quiz app for the Kerala PSC Child Development Project Officer syllabus.

## Advanced Practice question bank

The app includes 8,400 Advanced Practice questions: 400 for each of the 21 syllabus modules. The current authored bank is stored in [`advanced-practice.js`](advanced-practice.js).

The question-writing and selection approach, including the checks applied to the bank and the fallback behavior, is documented in [Advanced Practice question method](docs/advanced-practice-question-method.md).

## Run locally

This is a static web app with Vercel API functions. Run the project with the Vercel CLI after configuring the required environment variables.
